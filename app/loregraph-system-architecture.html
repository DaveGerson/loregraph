Generic system · initial validation corpus: Eberron

Approved direction · v2.0

One evidence system for lore, play, and notes.

LoreGraph turns books, rules, campaign records, and everyday notes into cited answers and living continuity. A generic evidence ledger powers Neo4j Aura, Obsidian, and the application without making any one setting, rules system, or database the source of truth.

Ontology strategy

A generic kernel, extended by bounded profiles.

The core is domain-neutral. Lore, tabletop play, mechanics, and personal work add query-value types without redefining provenance or truth.

Loader mechanics

Eight guarded stages from file to answerable graph.

    Storage contract
    
          
    One write model, three purpose-built read surfaces.
    
        
    
        
    A projection may fail, change shape, or be replaced without losing the semantic source of truth.
    
      
    
      
    
        
    
          
    Authoritative
    Evidence ledger
    
          
    StoresJSONL records, immutable IDs, evidence, assertions, review items, vectors
    
          
    OptimizesPortability, audit, replay, deterministic stage recovery
    
          
    Never assumesAura, Obsidian, Eberron, or a particular model provider
    
        
    
        
    
          
    Projection A
    Neo4j Aura
    
          
    StoresTyped nodes, assertion/evidence edges, direct traversal edges, indexes
    
          
    OptimizesNeighborhood queries, hybrid retrieval, timelines, continuity checks
    
          
    Rebuild ruleMERGE by stable ID; loader namespace limits cleanup
    
        
    
        
    
          
    Projection B
    Obsidian vault
    
          
    StoresMarkdown dossiers, source notes, YAML properties, backlinks, optional evidence
    
          
    OptimizesHuman browsing, editing, capture, portability, notebook-only use
    
          
    Safety ruleOnly marked generated files are eligible for cleanup

    Three implementation tracks
    
          
    Start at the lowest useful operational weight.
    
        
    
        
    The tracks are additive. A cheap pilot can validate questions before the full durable model is loaded.
    
      
    
      
    
        
    
          Recommended first
          
    Ledger + Obsidian
    
          
    The easiest durable path: ingest locally, audit, and generate a vault. Add hosted extraction only after a small review sample.
    
          
    • No database required
    • Human-inspectable output
    • Preserves the future Aura path
    
        
    
        
    
          Disposable discovery
          
    Simple Neo4j pilot
    
          
    Run pre-parsed approved text through one closed profile to validate labels, graph questions, and visual value.
    
          
    • Fast feedback on one source
    • Not the canonical truth model
    • Rebuild after the pilot
    
        
    
        
    
          Full capability
          
    Ledger + Aura + app
    
          
    Use after the journeys are proven: hybrid retrieval, bounded graph expansion, campaign-safe contexts, and operational views.
    
          
    • Rich cross-source traversal
    • Player/DM policy filters
    • Same portable ledger
    
        
    
      
    
    
    

    
    
      
    
        
    
          
    Token discipline
    
          
    Spend models on ambiguity, not plumbing.
    
          
    
            Page recovery, chunking, hashes, exclusions, known aliases, schema validation, audit, projection, and most
            filtering are local. Every paid stage is opt-in and budgeted.
          
    
          
    
            changed-only
            per-source consent
            compact profiles
            local embeddings

    Implementation sequence
    
          
    Prove each journey before scaling the corpus.
    
        
    
        
    Every phase produces a usable artifact and an evaluation result, not merely more graph volume.
    
      
    
      
    
        
    Phase 01 · Local spine
    Parse & inspect
    Three representative sources, generic defaults, local ledger, Obsidian output.
    • Rights manifest
    • Chunk/address audit
    • Idempotence test
    • No model required
    
        
    Phase 02 · Lore pilot
    Calibrate Eberron
    Activate the optional pack on a small sample; validate contested, temporal, and alias questions.
    • 10–30 chunk extraction
    • Identity precision sample
    • Citation coverage
    • Generic profile regression
    
        
    Phase 03 · Play & notes
    Exercise all journeys
    Add one campaign plus ordinary project notes; test continuity and work recall.
    • Plan vs occurred
    • Player-safe leakage suite
    • Decisions/questions/tasks
    • Ruleset pinning
    
        
    Phase 04 · Scale
    Load incrementally
    Expand books and campaigns only when audit quality and query usefulness hold.
    • Changed-only jobs
    • Review queue cadence
    • Aura hybrid retrieval
    • Pack/version governance
